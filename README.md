### Instalación 

#### Requisitos
Para poder correr la notebook correctamente, es necesario contar con [Conda](https://docs.conda.io/en/latest/miniconda.html) o Miniconda instalado.

#### Instalación del Entorno
Hemos proporcionado un archivo `environment.yml` con todas las dependencias necesarias (numpy, scipy, scikit-learn, pandas, tqdm, jupyter).

1. Crea el entorno ejecutando el siguiente comando en la terminal desde el directorio raíz del proyecto:
   ```bash
   conda env create -f environment.yml
   ```

2. Una vez que termine de instalarse, activa el entorno:
   ```bash
   conda activate amia_2026_tp5
   ```

3. Finalmente, inicia Jupyter Notebook para abrir el archivo:
   ```bash
   jupyter notebook
   ```
